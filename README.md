## Run

```sh
node main.ts
```

`main.ts` copies `entry.png` to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR`
when set), after checking the PNG signature and the 1 MiB limit. Two runs
write identical bytes, so the entry is fully deterministic.
